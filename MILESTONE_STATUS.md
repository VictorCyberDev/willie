# Willie milestone status

`FINAL_REVIEW_PACKET.md` is the **single authoritative M0–M28 acceptance matrix** for the Winner Release.

This file intentionally does not duplicate milestone statuses, provider claims or blockers. That prevents older M0–M16 evidence from conflicting with the continuing M17–M28 release state.

Use:

- `FINAL_REVIEW_PACKET.md` — authoritative statuses, checkpoint commits, tests, provider/live evidence, blockers and release verdict.
- `docs/execution/M0.md` … `docs/execution/M16.md` — historical milestone evidence for the Codex-built foundation.
- `docs/execution/TWITCH_CLI_ACCEPTANCE.md` — official Twitch CLI raid evidence.
- `REAL_VS_SIMULATED.md` — evidence-class definitions and disclosure rules.

No milestone may be described as `LIVE_ACCEPTED` unless the exact real-provider gate documented in the final review packet has genuinely passed.

# Acceptance instructions
Use Node24 and pnpm10.18.3. Copy .env.example to a private .env; never commit secrets. Install with pnpm install --frozen-lockfile. Start clean isolated Postgres via docker-compose.dev.yml and set TEST_DATABASE_URL only to an empty test database. Run migrate and seed as documented in README. Run pnpm lint, pnpm typecheck, pnpm test, pnpm test:property, pnpm test:integration, pnpm test:contracts, pnpm build, pnpm test:e2e, pnpm test:m9 and pnpm docker:build. Install Chromium with pnpm exec playwright install --with-deps chromium. Never point integration tests at owner production data. Actual final counts/results belong in FINAL_REVIEW_PACKET.md.

# Willie SDK
Public source entry packages/sdk/src/index.ts exposes WillieAdapter, ContributionProvider, TransitionEvidenceProvider, PlatformTransport, PlatformCapabilities, AdapterContext, NormalizedProviderEvent, AdapterHealth. Lifecycle configure→validateConfig→connect→consume→disconnect plus health. Host injects clock, fetch and durable emit; only server domain owns custody. Host atomically deduplicates provider+eventID and semantic effect before advancing cursor. ButtonAdapter uses public SDK only; SignedWebhookAdapter verifies raw HMAC/timestamp. Run pnpm adapter:test. Source types do not imply published-package acceptance or live provider acceptance.

# Willie
**One live thing. Many communities.**

Willie is a shared live object that communities change together and creators can safely hand from one live stream to another.

Communities wake a six-segment luminous artifact through bounded chat contributions. A creator prepares a destination, Willie observes matching Twitch raid evidence, and the receiving creator explicitly holds to receive. Custody changes atomically with its state, a Passport stamp and a verifiable Receipt.

A Twitch raid is evidence that the creator-to-creator transition occurred. The raid itself does not automatically transfer Willie. No raid size grants authority.

The public Judge Mode is a clearly labeled simulated replay using the same domain engine. Live acceptance and pending provider configuration are enumerated in FINAL_REVIEW_PACKET.md. Do not describe contract fixtures as live Twitch behavior.

Codex work includes domain architecture, property testing, provider contract research, adapter implementation, independent review and repairs. The canonical session ID must be supplied from actual session metadata before submission.

A raid shouldn't reset the story.

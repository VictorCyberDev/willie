# Threat model
Assets: custody integrity, provider credentials, campaign control, provenance. Attackers: unauthorized creators, malicious viewers, leaked overlay URLs, forged/replayed webhooks and concurrent browser sessions. Trust boundaries: provider to ingress, client to server, server to Postgres. Primary defenses: authentication and campaign roles; raw-body signatures and timestamp freshness; unique event IDs; row locking and version checks; append-only ledger; explicit destination consent; pause on unprovable evidence loss. Independent review findings and repairs are tracked in milestone evidence. No acceptance claim substitutes for review.
